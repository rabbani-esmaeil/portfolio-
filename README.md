# وب‌سایت پورتفولیو با پنل مدیریت محتوا (CMS)

این پکیج شامل وب‌سایت شخصی و رزومه دوزبانه (فارسی / انگلیسی) به همراه پنل مدیریت محتوای بدون سرور (**Sveltia CMS**) است.

## 📁 ساختار فایل‌ها
- `index.html`: صفحه اصلی سایت با لود داینامیک داده‌ها از `data/content.json`
- `data/content.json`: تمام متون فارسی و انگلیسی سایت
- `admin/index.html`: پنل مدیریت محتوای گرافیکی (تحت وب)
- `admin/config.yml`: پیکربندی پنل مدیریت برای ویرایش فیلدهای `data/content.json`
- `assets/`: تصاویر پروفایل، آواتار و استیکرها

---

## 🚀 راهنمای راه‌اندازی و استفاده از پنل ادمین

### روش ۱: میزبانی رایگان روی GitHub Pages (پیشنهادی)
1. فایل‌های داخل این پوشه را در یک مخزن (Repository) جدید گیت‌هاب آپلود کنید.
2. فایل `admin/config.yml` را باز کرده و در خط `repo: your-username/your-repo-name` نام کاربری و نام مخزن گیت‌هاب خود را جایگزین کنید.
3. در تنظیمات گیت‌هاب (Settings > Pages)، قابلیت GitHub Pages را روی شاخه `main` فعال کنید.
4. آدرس سایت شما فعال می‌شود (مثلاً `https://username.github.io/portfolio/`).
5. با رفتن به آدرس `https://username.github.io/portfolio/admin/` می‌توانید با یک توکن گیت‌هاب (Personal Access Token) وارد شوید و تمام متون سایت، تجربیات، تحصیلات و اطلاعات تماس را ویرایش کنید و با دکمه Save تغییرات در لحظه روی سایت اعمال می‌شود.

### روش ۲: ویرایش مستقیم آفلاین
کافیست مستقیماً فایل `data/content.json` را در ویرایشگر متنی باز کرده و هر متنی را تغییر دهید. صفحه `index.html` خودکار آخرین اطلاعات را نشان خواهد داد.
